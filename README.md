# 🪙 Orb Translations — Коммерческая платформа продажи переводов

> Современное веб-приложение для публикации и продажи художественных переводов визуальных новелл и манги на **GitHub Pages** с приёмом оплаты в криптовалюте (**USDT**) через HD-кошелёк (**xPub**) и интерактивным чтением прямо в браузере.

---

## 🌟 Ключевые возможности

1. **Внутренняя валюта «Орбы»:**
   * Номинал: **1 Орб = 1 USDT**.
   * Первая работа стоит **1 Орб**.
   * Пополнение баланса через HD-кошелек с генерацией уникальных адресов для каждого заказа.

2. **Безопасная модель без нарушения авторских прав:**
   * На сервере/репозитории хранятся **только превью-страницы и текстовые скрипты перевода**.
   * Защищённые авторским правом оригинальные изображения на сайте **не хранятся**.
   * Пользователь загружает свой купленный архив (`.zip`) или папку с графикой, а читалка на лету накладывает перевод в браузере!

3. **Разграничение прав и бесплатное превью:**
   * **Незарегистрированные гости:** могут просматривать первые $N$ страниц превью каждой работы (по умолчанию 3 страницы). При попытке листать дальше открывается стильный замок с предложением регистрации и покупки.
   * **Зарегистрированные пользователи:** пополняют баланс Орбов, покупают переводы и открывают полный просмотр с наложением.
   * **Администратор:** доступ к закрытой панели управления работами, ценами, страницами превью и настройкам кошелька.

4. **Прямой крипто-перевод через xPub (HD Wallet):**
   * Использование Master Public Key (`xpub...`).
   * На каждый новый заказ генерируется уникальный адрес в сети **TRC-20** (Tron) или **BEP-20** (BSC) по пути деривации `m/44'/.../0/index`.
   * Динамический QR-код, таймер оплаты и проверка поступления средств.

5. **Интерактивная читалка:**
   * 1 или 2 разворота (как в манге).
   * Выбор языка перевода из скрипта (`【Русский】`, `【English】`, `【日本語】`).
   * Наложение текстовых блоков, диалоговых рамок (1–5) и стилей шрифтов прямо поверх официальных картинок пользователя.

## 🚀 Запуск и публикация на GitHub Pages

1. **Локальный просмотр:**
   * Просто откройте `index.html` в любом современном браузере.
   * Или запустите локальный веб-сервер:
     ```bash
     npx serve .
     ```

2. **Публикация на GitHub Pages:**
   * Инициализируйте Git в папке `Site/`:
     ```bash
     git init
     git add .
     git commit -m "Initial release: Orb Translations Storefront & Reader"
     git branch -M main
     git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
     git push -u origin main
     ```
   * В настройках репозитория на GitHub перейдите в **Settings -> Pages**.
   * В разделе **Build and deployment -> Branch** выберите ветку `main` и папку `/ (root)`.
   * Нажмите **Save**. Через 1–2 минуты сайт станет доступен по адресу:
     `https://<ваш-логин>.github.io/<имя-репозитория>/`
